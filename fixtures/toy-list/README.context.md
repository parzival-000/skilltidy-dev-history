# Tiny List Card: context for reviewers

This toy skill formats small integer lists as plain-text cards. Its main contract is in `SKILL.input.md`. It is a synthetic development fixture, not a skill to install or publish as a real product.

The normal workflow preserves input order and duplicate values. Explanation mode is separate and reads the reference only when requested. This README supplies context; it does not override the exact strings, validation order, or permissions in the main file.
